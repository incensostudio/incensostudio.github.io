# Incenso Studio — Website

Public marketing site for **Incenso Studio** (Tripoli, Lebanon), live at
**https://incensostudio.com**. A single-page hero: interactive grid background,
the incenso wordmark, Google-reviews trust line, WhatsApp "Book Now" CTA,
Instagram story highlights, live open/closed status, and contact links.

Self-contained static HTML (only Google Fonts loads externally). No backend.
Served by GitHub Pages from this repository's `main` branch.
